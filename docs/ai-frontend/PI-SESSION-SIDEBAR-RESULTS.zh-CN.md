用户确认范围为“会话侧栏全部交互：滚动、展开折叠、分组、预览、菜单、快捷键与拖动”。最新源码和生产资源已经更新。此前的 6px 滚动条版本由本次实现替代。

## 已接入的交互

| 交互 | 当前行为 |
|---|---|
| 滚动 | 原生通道贴边，命中宽度 14px；普通滑块宽 6px，直接悬停／按住时加粗到 10px；长度按可见高度／内容高度变化，保留 Pi 的悬停、焦点、滚动显示及 300ms 保持 |
| 展开折叠 | 默认折叠轨道、明确展开入口；分组可独立折叠；设置和后台任务入口固定底部 |
| 分组和排序 | 独立置顶区；今天／昨天／近 7 天／近 14 天／更早；最近更新、最早创建、名称、最近创建四种排序；排序通过宿主保存并在重载后恢复 |
| 预览 | 120ms 预取、500ms 悬停显示、160ms 离开关闭；显示最近问题／回答、时间、状态和消息数；查看预览保持当前会话，点击“打开会话”才切换；滚动、外部点击、Escape、窗口隐藏等关闭 |
| 菜单和多选 | 左键“…”／右键菜单，重命名、置顶／取消、删除；Ctrl/Cmd 点击切换选择，Shift 锚定范围；批量删除 3200ms 内再次确认，改变选择集合重新要求确认；只读／运行中记录禁止删除 |
| 快捷键 | 列表方向键、Home／End、Escape；Ctrl/Cmd+B 切换侧栏，避开输入框和富文本编辑器；菜单保留键盘导航、边缘定位和焦点恢复 |
| 拖动 | 原生滑块拖动与侧栏调宽区域分离；调宽保留指针捕获、Escape 取消、拖到阈值折叠、双击还原和键盘步进；宽度继续存宿主偏好 |

名称排序／搜索时使用平铺结果；日期排序结合时间组。分组中的“更早”表示超过 14 天的记录。侧栏中的会话仍消费现有 ChatStore 和 Praat RPC，聊天仍由 assistant-ui 驱动。

## 来源和适配

固定来源为 [PI-Desktop Sidebar.tsx](https://github.com/vastsa/PI-Desktop/blob/0d47d26769ecbeca1c3ab56fa83b58a91de8190e/apps/desktop/src/components/Sidebar.tsx)，提交 `0d47d26769ecbeca1c3ab56fa83b58a91de8190e`、LGPL-3.0。完整原始 `Sidebar.tsx`、预览、分组、调宽、偏好、状态、删除确认和侧栏样式等 12 个文件原样保存在 `ai/third_party/pi-desktop/upstream/sidebar/`，逐字节比对通过：[来源记录](verification/pi-sidebar-source-result.json)。

实际运行代码在 `ai/frontend/src/pi/sidebar/`，`App.tsx` 挂载独立会话侧栏，`SessionRow.tsx` 接入预取、预览和多选。分组模块保留原逻辑；悬停、删除计时和预览定位从源代码迁入。渲染器和数据类型适配本项目宿主，保留现有单条删除确认、草稿／阅读位置及后台任务隔离。上游悬停钩子另修复了“移出 50ms 后返回同一行仍被关闭”的定时器问题。

Pi 原始样式本身仍是 6px 通道，因此本次按用户“难选中”的反馈扩大命中宽度；这是一处明确的可用性适配。项目管理、跨项目会话拖放、归档和通知不属于用户确认的本轮范围。没有接入 Pi Agent、Pi 全局 store 或 Electron IPC。

许可、具体修改及可替换／重建方法见 [NOTICE](../../ai/third_party/pi-desktop/NOTICE.md)。`dist/pi-desktop-source` 同时保存原始文件、实际使用的修改源码、完整前端重建输入和许可；已经检查实际使用源码及通知与生产分发一致。
