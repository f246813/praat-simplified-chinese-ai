# 会话历史省略号菜单验收（2026-10-04）

会话历史工具栏的双向箭头已替换为省略号，一级菜单为“整理侧边栏”和“聊天排序方式”，二级菜单侧向展开。

- 整理侧边栏：按项目、按远程连接、在一个列表中。根据会话实际记录的项目路径和连接身份分组，支持展开/折叠。置顶与自定义分区保留原有成员和位置。
- 聊天排序方式：保留原有“最近更新、最早创建、按名称、最近创建”。按用户确认，“最近更新”只保留原有的一项。
- 菜单支持悬停、点击、方向键进入/返回、Escape 关闭并还原焦点、点击外部关闭、窗口边界避让及当前选项勾选。分组和排序偏好由宿主持久化，关闭并重开仍生效。
- 新会话记录当前宿主工作目录；分叉继承来源项目与连接。既有本地现代记录补齐缺失来源，已有来源不覆盖，旧记录库保持只读。滑条文件与本次修改前逐字节相同，14px 点击区域与 68px 最短滑条保留。

当前宿主实际只有本地连接。选择“按远程连接”会将本地会话放入“本地”；已有远程来源元数据可独立分组。本次没有添加 SSH 连接管理或远程执行服务，也不把模型 API 地址当作远程连接。

实现沿用已有代码：

- Codex 固定版本 `ab45264919aaeb8a421cc156f1a5459ef9d60b72` 的 `ThreadSortKey.ts`、`SortDirection.ts` 原样复制并参与排序，完整 `ThreadListParams.ts` 保留作为项目 cwd 协议参考。
- Pi 固定版本 `0d47d26769ecbeca1c3ab56fa83b58a91de8190e` 的已有路径归一化函数和原样摘取的 `folderNameFromPath` 用于项目标识/名称，菜单沿用已有 Pi 样式。
- 二级菜单机制使用已经安装的 Radix Dropdown Menu 2.1.24（MIT），按官方 Sub/Portal/RadioGroup 组合接入。该包从既有间接依赖改为精确直接依赖，没有新增安装包。

Codex 公开仓库没有桌面 React 侧栏菜单/分组组件。公开部分原样搬运；未公开的渲染层采用现成 Radix/Pi 组件与宿主数据拼接，没有声称复制不可访问的桌面源码。原文件、Git blob、SHA-256、许可证与完整可替换前端源码均随正式资产提供，见 [来源说明](FRONTEND-SOURCES.md)。

验证：TypeScript 编译通过，26 项前端单元检查、48 项 Python 检查、10 项浏览器检查全部通过；正式离线资产构建通过。真实 pywebview/WebView2 的隔离窗口验证了菜单、来源分组、设置重载、分区保留及滑条尺寸，未调用模型或 Praat 执行器。隐藏窗口通过 DOM 事件驱动正式处理器；实际鼠标悬停与键盘导航另由浏览器检查验证。远程验收记录明确为隔离样例，没有连接远程主机。
