# 历史栏原生滚动条

侧栏采用 WebView2／浏览器原生滚动条，样式位于 `src/pi/sidebar/styles.css`。当前通道宽度为 14px，静止时 4px 透明边框形成约 6px 可见滑块，悬停／拖动时边框变为 2px；CSS 设置 `min-height:68px`。原生滑块长度仍随内容和视口变化，实际最小尺寸受浏览器影响。

滚动显示逻辑复用 Pi 局部提取物，来源与 LGPL 交付说明见 [来源说明](FRONTEND-SOURCES.md)。这些尺寸是当前可用性适配参数，不是所有缩放比例下的尺寸保证。检查应分别核对通道 computed style、长／短列表的实际滑块和原生指针拖动；DOM 滚动事件不能代替拖动检查。
