# Modern host contract v1

Sidebar preferences: validated/persisted
`preferences.sidebar_grouping:'project'|'connection'|'list'` defaults to
`project`. Switching changes ordinary-history presentation; pinned/custom
section membership stays intact. Partial saves retain other preferences and
credentials, including the `sidebar_sort` value.
Session summaries additionally expose `projectPath:string|null`,
`connectionId:string`, `connectionLabel:string`. Additive modern SQLite columns
persist these origins. The host supplies its real local workspace for new
sessions and missing local modern origins, preserves recorded remote origins,
and leaves legacy project paths unknown. Forks inherit source origins. Remote
model API URLs are not connection identities; this extension adds no remote
connector or executor.

Python exposes only `window.pywebview.api.rpc(method, params)` (Promise). Errors reject with sanitized text. No arbitrary Python/file/script execution.

- `bootstrap {}` -> `{sessions: Session[], sections:HistorySection[], settings: Settings, tasks: Task[], host:{name,version,cloudAllowed,praat:PraatSnapshot|null}, providers: {label,base_url,model,hint}[], models: {id,contextWindow,maxTokens}[]}`
- `sessions.create {title?,sectionId?:string|null}` -> Session; validates destination before creation and appends membership.
- `sections.create {name,appearance?:{icon:string|null,color:string|null}|null}` / `sections.update {sectionId,name,appearance?}` -> HistorySection. Stable identity, trimmed 1–100 character name, 64-byte appearance fields; omitted appearance retains current value. Built-in pinned section cannot be renamed or deleted.
- `sections.delete {sectionId}` -> OrganizationSnapshot; detaches membership/order, retains all conversation/message/evidence/archive data.
- `sessions.section {sessionId,sectionId:string|null,beforeSessionId?:string}` -> OrganizationSnapshot. Explicit nullable destination is required. One membership; append or insert before a member of the destination in a transaction. Pinned/custom membership mutually exclusive. Legacy custom/default membership uses modern sidecar metadata; legacy pinned forbidden.
- `sessions.archive {sessionId,archived:boolean}` / `sections.archive {sectionId:string|null,archived:boolean}` -> OrganizationSnapshot. Local archive aggregation; active members reject the whole archive before mutation. Restore retains original membership. `null` targets ordinary history; omitted destination rejected. Archived sessions remain readable, movable and forkable; submission refused until restored.
- `sessions.fork {sessionId}` -> new Session; full current snapshot under task lock, independent message/activity ids, historical context/summary/evidence preserved, empty draft/reading position, source metadata recorded. Running fragments become interrupted; no task creation, executor calls or replay. Custom section inherited; pinned/archived flags reset. Legacy source opened read-only, child is a modern writable session.
- `sessions.get {sessionId}` -> `{session: Session, messages: Message[], cursor:number}`; live messages and the event watermark are captured under the same lock. Replay message/activity/delta events only when `seq > cursor`; task events remain independently applicable.
- `sessions.search {searchTerm,archived?:boolean}` -> `{sessionIds:string[]}`; compact persisted user/assistant body search across modern and visible legacy history.
- `sessions.group {sessionIds:string[],action:'delete'|'detach'|'archive'}` -> OrganizationSnapshot; batch group actions validated by the organization service.
- `sessions.context {sessionId,text?,attachmentIds?:string[]}` -> `{sessionId,model,estimated:true,inputTokens,overheadTokens,contextWindow:number|null,reservedTokens:number|null,availableTokens:number|null,percent:number|null,tokenMode,windowSource:'metadata'|'configured'|'unknown',reason,exclusions:string[]}`. Read-only next-turn heuristic shared with compaction: saved summary, completed history, evidence, draft and text attachments. No target capture, compression, model request or message write. Max 100000 draft characters, 8 attachments, 1 MiB total text attachments; legacy forbidden. Unknown windows have no percentage. Provider reserve is for compaction, not an output cap.
- `sessions.rename {sessionId,title}` -> `{ok:true}` (legacy forbidden). `sessions.delete {sessionId}` -> `{ok:true}` (active deletion forbidden; archived legacy entries may be hidden through modern sidecar metadata without deleting the source database).
- `sessions.pin {sessionId,pinned:boolean}` -> authoritative `Session` including pinned section membership; strict boolean, modern sessions only, allowed while running. Existing `session_pins` remains synchronized with the protected built-in section. Unpin moves to ordinary history; idempotent pin preserves order.  Bootstrap/list/get expose boolean `pinned`; legacy remains read-only/unpinned.
- `sessions.view {sessionId,draft?,scroll?,anchor?}` -> `{ok:true}`. `anchor` is the durable reading position `{messageId,offset}`: a message id plus the viewport offset of that row's top edge. It is what survives a windowed transcript; `scroll` is only the pixel fallback used when no anchor exists yet. The store validates it (non-empty bounded id, finite offset) and refuses the write outright rather than storing a position that cannot be resolved. A partial write leaves the other fields untouched. Legacy ids are still refused.
- `tasks.submit {sessionId,text,attachmentIds?:string[]}` -> Task (same-session overlap rejected; others continue)
- `tasks.cancel {taskId}` -> `{ok:true}`
- `events.poll {after:number}` -> `{events: Event[],cursor:number,reset?:boolean}` (poll every 150-300ms, refresh on reset)
- `settings.get {}` -> Settings
- `settings.save {settings:Partial<Settings>}` -> Settings; merge only supplied editable fields with the current host configuration. Quick model/strength changes never send credentials or endpoints and do not change an already captured task configuration.
- `settings.test {kind:'text'|'audio',settings:Settings}` -> `{status,reason,details?,identity?}`. Requires explicit runtime cloud permission for remote URLs; no implicit requests.
- `attachments.choose {}` -> Attachment[] (native picker)
- `attachments.import {name,mime,data:string}` -> Attachment (Base64 bounded imported bytes; never stored in history)
- `attachments.preview {attachmentId}` -> `{name,mime,text?:string,dataUrl?:string}` (bounded preview)
- `links.open {url}` -> `{ok:true}` (http/https only, native confirmation)

Session: `{id,title,created,updated,readOnly:boolean,pinned:boolean,draft:string,scroll:number,anchor:{messageId:string,offset:number}|null,sectionId:string|null,sectionPosition:number|null,archived:boolean,forkedFrom:string|null,forkedFromTitle:string|null,projectPath:string|null,connectionId:string,connectionLabel:string,timeGroupDetached?:boolean}`. Legacy IDs `legacy:<id>` are read-only and carry `anchor:null`. New organization tables and the anchor column are additive; legacy membership/archive lives in the modern metadata database.
HistorySection: public Codex `ThreadSection` `{id,name,appearance:{icon:string|null,color:string|null}|null}` plus local `builtin:boolean` projection. Pinned id: `01984de2-8f74-7c91-a3b2-5c5e937cf318`. OrganizationSnapshot: `{sessions:Session[],sections:HistorySection[]}`. Public source and adaptation boundaries are recorded in `ai/third_party/codex/NOTICE.md`.
Message: `{id,role:'user'|'assistant',content:string,status?:'running'|'complete'|'partial'|'cancelled'|'failed'|'interrupted',taskId?:string,attachments?:Attachment[],activities?:Activity[]}`.
Activity: `{id,type:'progress'|'thinking'|'tool'|'compression',text?:string,name?:string,args?:object,result?:any,status?:string,execution?:string}`. Only real backend content.
Task: `{id,sessionId,status,model,created}`.
Event: `{seq,sessionId,taskId,type:'task'|'delta'|'activity'|'message',payload:any}`. task payload Task; delta payload `{messageId,text}`; activity payload `{messageId,activity:Activity}`; message payload Message (authoritative replacement).
Attachment: `{id,name,mime,size}`. Imported material is stored separately in host-owned storage; user messages store metadata only. Text is passed as user material, WAV via existing bounded TaskMaterials.

Settings: `{api:object,local:object,preferences:object,analysis:object,alignment:object}`. api matches ApiConfig plus `token_mode:'auto'|'manual'|'provider',top_p?:number,presence_penalty?:number`. local matches QwenConfig plus token_mode. Blank `api_key` means preserve existing; `clear_api_key:true` explicitly clears; `has_api_key` is read-only. Credentials never returned; transient user input only. Unknown fields in original config preserved on save. API fields include enabled,locked,label,base_url,model,request_timeout_sec,stop_local_service,use_world_knowledge,audio_input_enabled,thinking_level,force_deep_thinking,plan_temperature,max_context_tokens,plan_max_tokens. preferences: `{theme:'system'|'dark'|'light',font_size:number,send_key:'enter'|'ctrl-enter',smooth_stream:boolean,sidebar_width:number,conversation_width:number,sidebar_sort:'recent'|'oldest'|'name'|'created',sidebar_grouping:'project'|'connection'|'list'}`. Sorting is validated and persisted by the host; the four modes mean recent update, oldest creation, name, and recent creation. `sidebar_width` is clamped to 240–520 and `conversation_width` to 560–4000 on save; a partial `preferences` patch preserves every other key. These two are window-partition sizes, and they are stored here rather than in browser storage because the WebView2 profile is private mode and is deleted on close. Model metadata unknown => auto must request explicit real window/manual settings, not invent limits. Existing user values retained; no universal new sampling defaults.

Safety: restore conversation context/evidence only; never replay execution. Close marks unfinished tasks interrupted. Original legacy SQLite opened mode=ro. Praat lock covers refresh/identity check/select/execute/read; unknown delivery poisons dispatcher until explicit desktop restart/reconciliation. The interactive desktop honors the enabled API configuration without a CLI flag; startup and settings saves send no model requests, and remote tests retain their confirmation dialog. This host policy authorizes only the enabled API endpoint, not a remote endpoint entered as a local model. Direct service construction remains cloud-restricted unless explicitly configured; `--allow-cloud` remains an explicit override. Development smoke uses isolated paths and mock execution.

PraatSnapshot: `{pid:number,objects:{id:number,className:string,name:string,selected:boolean}[]}`. This is the native menu's launch-time object snapshot, not a live measurement or execution target. It is returned only when the explicitly bound parent process/executable and native PID marker match; otherwise null. Task submission still captures and validates its own current target through the existing serialized executor.

Normal desktop path: open this project's Praat, read a file, View & Edit, then the existing Frontend → Start frontend menu. No auto-launch, no model startup/probe. The shipped native start/quiet handshake only performs dependency/asset preflight; explicit legacy service CLI remains unchanged. First production React bootstrap writes a private readiness record (actual executor type and parent PID); there is no extra public testing RPC. Startup errors are credential-sanitized, visible even under pythonw, and diagnosed in runtime records. Bound parent closure closes the desktop; repeat menu use focuses/restores the existing window.

Implementation bounds, polling intervals and layout clamps describe current code parameters, not independently approved product policy. Frontend TypeScript shapes are maintained in `ai/frontend/src/types.ts`; Python validation is in `modern_app.py`, `modern_settings.py` and the storage/organization modules.
