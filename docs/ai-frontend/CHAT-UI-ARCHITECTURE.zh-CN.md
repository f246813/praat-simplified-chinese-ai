# 现代 AI 聊天前端架构

现代客户端使用 assistant-ui／React、Tiptap 和本地 Markdown 渲染链，桌面壳为 pywebview／Windows WebView2。Python 应用服务管理会话、设置、任务和 Praat 执行。Pi 与 Codex 的固定来源提供局部交互、协议和算法，来源边界见 [来源说明](FRONTEND-SOURCES.md)。

## 数据与执行

`ChatStore` 是前端宿主状态入口；assistant-ui external-store runtime 展示消息和输入。前端通过单一 `rpc(method, params)` 白名单调用 Python，接口见 [宿主契约](HOST-CONTRACT.md)。生产浏览器页面缺少宿主时拒绝执行；开发演示需要开发模式、loopback 与显式 demo 参数。

`modern_app.py` 为每项任务捕获配置、会话、取消信号和目标。不同会话可后台运行；同会话拒绝重叠提交。Praat 工具通过串行执行器核对目标并执行。切换当前会话不改变后台事件归属。恢复历史仅恢复上下文、摘要与专业证据，续聊重新捕获目标，历史操作不会重放。

现代 SQLite 默认位于 `ai/runtime/modern/sessions.sqlite3`；旧数据库以只读连接打开。旧记录的分区、归档与移除入口元数据保存在现代库。现代会话删除移除关联记录；归档旧记录的删除仅隐藏本应用入口，原库保留。

## 界面

- 默认折叠侧栏提供会话管理、标题与正文搜索、置顶、自定义分区、项目／连接分组、排序、多选和悬停预览。底部设置入口在折叠时仍可用。
- 输入编辑器支持 Markdown 序列化、IME 防误发送、输入历史、会话草稿、附件选择／粘贴／拖入和预览。斜杠补全连接新建、设置、取消与附件动作。
- 消息展示包含实际思考／进度／工具事件、折叠详情、流式 Markdown、代码、公式和离线 Mermaid。复制与右键菜单连接当前可用动作。
- 长历史保留已加载数据，仅挂载一段消息行。阅读锚点为 `{messageId,offset}`；历史展开和卡片展开用内容高度／行偏移补偿。缩略图只导航已挂载行。
- 会话内查找搜索当前渲染正文，使用 CSS Custom Highlight API；侧栏搜索通过宿主 SQLite 返回命中会话 ID。
- 设置提供模型、预算、采样／思考、Praat／音频、外观和存储分类，以及已归档会话页面。局部设置保存合并指定字段。
- 侧栏与对话带可拖动、键盘调整和还原，宽度保存在宿主偏好；WebView2 私有配置不会作为持久存储。

## 模型与预算

本地与 API 参数分别存储，运行中任务使用提交时配置。自动、手动与服务商决定三种 token 模式使用共享预算逻辑；近满载时生成摘要，原消息和证据保留。未知模型窗口不能从模型名称推断。固定模型元数据及适用端点见 [模型来源](PI-MODEL-SOURCES.md)。

桌面入口允许当前启用的 API 配置；启动及保存不发模型请求，连接测试使用宿主确认。远程地址填入本地配置仍受端点校验。API Key 不通过设置读接口返回。

## 当前实现限制

后台任务数、窗口行数、布局宽度及搜索命中上限是代码中的实现参数，见 [交互实现](PI-DESKTOP-GAP-AUDIT.zh-CN.md)。它们不表示独立的产品承诺。当前宿主没有远程连接管理；来源元数据可用于分组。本地路径没有 WAV 模型输入能力，思考内容取决于实际后端事件。会话内查找不覆盖未挂载行；会话分叉可用，消息编辑、单消息删除与重新生成没有 RPC。

构建和可复现检查入口见 [构建说明](BUILD-RESULTS.zh-CN.md)。检查夹具不能证明真实模型、所有实体输入法或完整声学流程的效果。
