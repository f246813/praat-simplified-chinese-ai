# 菜单鼠标移动闪烁修复

上一次圆点修复在 WM_MENUSELECT 中对整个 popup 调用 InvalidateRect。鼠标切换菜单项时，原生菜单已经绘制悬停状态，随后又被整张刷新，导致用户看到闪烁。

本次移除该路径的整菜单无效化：仅在本地模式有圆点时，投递一个自定义窗口消息；原生悬停绘制结束后，只绘制圆点的椭圆区域。API 模式不投递补画消息。保留打开、模式变化、关闭时已有的更新和绑定清理，以及模型/状态黑色文字、显存本地黑色/API灰色行为。

修改前通过 GitHub 插件检索 Microsoft Windows-classic-samples 的 WM_MENUSELECT/InvalidateRect 处理。实际复用本项目的原生消息分发、popup subclass 与 drawStatusDot；未复制外部代码或新增依赖，沿用文件既有 GPL 许可。

验证：原生构建通过。真实菜单16项检查通过，包括 API 与本地模式各48次连续鼠标移动，未选中的模型行在采样帧中保持不变；移动后、悬停和重开时，本地点保留，API无点。测试报告 `installer/verification/menu-flicker.json`。
