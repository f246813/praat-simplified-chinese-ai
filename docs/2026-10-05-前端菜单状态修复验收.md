# 前端菜单状态修复（2026-10-05）

上海时间 16:15 后开始。原生窗口顶部“前端”菜单：

- 显存预警：剩余显存 < 512 MiB 红色，512–1535 MiB 黄色，≥ 1536 MiB 绿色；无可用 GPU 数据显示“显存预警：不可用”，不误报绿色。圆点由 GDI 绘制，状态行禁用时保持彩色。
- 模型：本地显示当前预设的配置名，无预设时使用配置的模型文件名；云端显示“云端API模式”。
- 状态：配置不完整/本地文件缺失为“未配置”；有效配置且桌面已连接、进程身份匹配为“运行中”；有效配置而桌面未运行为“已停止”。模型按需加载，状态反映工作台生命周期。

根因：旧启动准备阶段写入 frontend_running=true、frontend_status="ready (modern desktop)"、frontend_model=""；菜单把准备标记与空模型直接显示。新菜单使用独立只读快照，在隐藏子进程中读取当前配置、验证真实桌面进程并采样 GPU，每 2 秒刷新。停止菜单正常关闭已记录且身份匹配的工作台，保留服务原有停止逻辑。

另一个实际原因：原有 XtAddTimeOut(2000) 的 Windows 实现按秒比较 Melder_clock，刷新间隔实际达到 2000 秒。现改为 Windows SetTimer(2000)，按两秒采样，也能在菜单消息循环中运行；关闭编辑器时清理其定时器。

修改前备份：backups/frontend-menu-20261005。以最新 speech-dictionaries-20261005 原生库为基底构建，保留词典管理、绿色选中边框/勾选和 MFA 选用功能。
