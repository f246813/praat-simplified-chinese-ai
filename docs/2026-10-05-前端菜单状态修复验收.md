# 原生前端菜单与模型状态

前端菜单的模式、模型与资源显示由原生控制层和 Windows 菜单绘制维护。API 状态与本地加载状态分开解释；鼠标移动、悬停、重开菜单和模式切换需在当前程序中分别检查。

模块职责、实现边界和检查入口见 [当前实现说明](CURRENT-IMPLEMENTATION.zh-CN.md#windows-启动菜单与安装)。
