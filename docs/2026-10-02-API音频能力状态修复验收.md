## 用户可见行为

截图中的错误现在显示为：

```text
status code: 400 · model: qwen3.7-flash
模型预设：不支持直接音频输入（官方文档）
音频实测：未能验证——资源 URL 或请求参数错误
当前设置：直接音频输入已关闭
```

这里“模型预设”与“音频实测”分别表达文档结论和实际探测结果。Qwen3.7-Flash 官方文档的输入模态是文本、图像、视频，参见[阿里云模型文档](https://help.aliyun.com/zh/model-studio/qwen3-7-flash)。已有预设原本关闭直接音频输入；本轮将这个结论明确显示出来。通用 URL / 参数错误 400 不能证明接口明确不支持音频，实测状态因此显示“未能验证”，保留当时的开关设置。

支持、明确不支持、未能验证、取消、正在验证及尚未验证均有独立文案。官方地址与按模型名称推定的第三方网关有不同的来源标记。基本音频验证成功会说明其不能保证精确声学测量或细微发音判断准确。“测试连接”明确标注仅测试文字请求。

长异常移到“查看详情”的只读、可滚动文本窗口，沿用密钥与 Bearer 凭据脱敏，异常正文最多保留 3000 字符。主窗口显示简短错误类别；没有 HTTP 响应时显示“status code: 未返回”。

探测记录绑定 API 地址、模型名、凭据及适配器版本；修改任一相关字段会清除旧结果，旧异步回调不能应用到新设置。保存及重开窗口保留匹配的实测记录。旧窗口或排队中的旧成功不能撤销之后的运行时明确拒绝；用户在纠正之后再次手动选择则仍可保存。观察时间在工作线程收到结果时捕获，手动编辑时间只参与冲突处理，不写入配置。
