# API 设置跳转到模型页

交付：`Praat.exe`、`Praat-model-settings.exe`，SHA256：`D252E6D60F304A42EA6F3B8606A57821DDC9EFB7E6E69210B4B7EFB7854F7366`。

点击语图顶部“前端 → API 设置”后直接打开 AI 对话窗口的“模型 → 云端 API”页。窗口已打开时复用原进程；正在初始化时排队跳转；重复点击能从聊天或其他设置页返回模型页。跳转保留未保存的设置、会话和草稿，不保存配置、不发起模型或连接测试请求。

原独立 Tk API 设置窗口的启动流程已移除。`start_api_settings.py`、`run_api_settings.py`、控制命令和 `api_settings.run_standalone` 兼容入口统一转向现代对话窗口。API 配置与服务商数据继续由共用模块保存；显式旧版聊天的 Tk 兼容类不影响现代菜单。

原生菜单复用词典窗口的 `CreateProcessW` 脱离进程方式，直接使用 Unicode 路径，不经过通用 Python 运行器的选中音频导出。项目与 Python 环境路径以 Windows 宽字符 API 读取，避免中文路径和反斜杠在转换时损坏。
