# 普通对话响应优化设计

用户已授权实施此前提出的优化，并要求在 API 高级选项新增“最高思考强度下，强制每次对话进行深度思考”。本设计记录具体执行边界，不再重复请求实施授权。

## 行为与优先级

- 新配置 `api.force_deep_thinking`，布尔值，默认 false，仅在 `thinking_level=high` 时生效。
- 明确寒暄、身份与能力介绍使用单次纯文本模型请求，不生成分析报告或交付覆盖表。最高档且新开关关闭时，该类请求关闭额外思考；开启时使用最高档。其他手动档位及“自动（服务端默认）”保留原含义。
- 纯概念问题可用独立纯文本解释，仍遵守知识权限和所选强度。涉及具体材料、对象、时间范围、指代、操作或继续原任务的请求保留分析管线。
- 明确简单时长查询可以直接调用既有 duration 工具，使用实际对象与既有校验。最高档强制思考开启时继续模型规划。未知或复合操作不猜参数、不靠另一次模型调用分类。
- 供应商适配：官方百炼 Qwen3 混合思考模型使用 enable_thinking；低/中以 thinking_budget 1024/4096 映射，高采用服务端默认思考预算。关闭时显式 false，自动不指定。其他网关维持兼容字段；强制最高档的思考字段被拒绝时不能悄悄关闭后声称成功。
- 普通回复逐段显示；最终回复替换并格式化同一段消息，只保存一次正式 assistant 消息。异常或取消不得把部分输出说成完整回复，也不得在已经显示内容后重新请求并混入重复正文。
- 每窗口复用同一事件循环及云端客户端；地址、模型、凭据或超时改变后替换客户端并关闭旧连接。关闭前端时取消当前请求并释放线程/连接。模型测试仍可注入离线替身，不真实调用用户 API。
- 非分析请求延后工具 schema、对象快照和 TaskMaterials 初始化。测量/音频分析继续使用原来的材料绑定、证据规则、安全检查和跨阶段预算。
- 记录首次文字、请求时长、整轮耗时、请求次数、重试、输入/输出/思考 token（服务商提供时）。使用单调时钟，不保存秘密或音频字节。
- 只更新 Python 前端及安装器载荷，保留当前 Praat.exe 和上一轮音频诊断修复。所有测试使用私有配置、合成数据、FunctionModel 或本地 HTTP 服务。

## 文件边界

`dialogue_policy.py` 负责保守分类及当前请求强度；`cloud_runtime.py` 负责连接与事件循环生命周期；`cloud_agent.py` 增加纯文本执行与请求时序；`cloud_workflow.py` 分流、延后材料、存储结果；`chat.py` 实现 UI 增量和关闭；`qwen.py` 共用供应商思考字段；`config.py` / `api_settings.py` 存储与显示设置。

高级选项展开后必须在屏幕内可操作；必要时使设置内容可滚动。强制设置需要保存重开验证。

## 验收

先证明旧行为失败，再验证：中英文普通对话仅一次无工具请求、混合测量不被分流、强制高开关仅影响高档、供应商实际请求字段、真实 SSE 首字先于完成且不重复、取消/失败不重发部分回答、连接复用/换配置/关闭、已有音频与分析回归。完整 Python / 安装器套件、用户所选 Python / Tk 9、独立只读复核和内嵌包哈希均通过才交付。不把离线性能试验当作真实云端延迟承诺。
