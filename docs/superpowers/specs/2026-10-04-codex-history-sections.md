# Codex 历史分区与分叉

用户要求在会话省略号／右键菜单加入分区和分叉，并为历史分区增加编辑、归档、新建和移除菜单。继续使用现有 assistant-ui、ChatStore 与 pywebview/WebView2，保留 14px 通道和 68px 最短滑块。

公开源固定为 openai/codex `ab45264919aaeb8a421cc156f1a5459ef9d60b72`。该树提供 ThreadSection 类型、创建／编辑／删除／移动 API、SQLite 分区语义和 thread/fork 协议；不包含桌面侧栏 React 组件。复用公开类型与语义，菜单渲染接入本项目既有组件，明确记录适配边界。

分区使用稳定 ID，名称编辑不影响归属；置顶是受保护的内置分区。单个会话只能归属一个分区，移动进自定义分区会取消置顶，置顶会移出自定义分区。自定义分区保留空分区，可折叠，菜单含编辑、归档全部会话、新建会话、新建分区、移除。移除仅解散归属，不删除历史；归档可恢复。用户已确认归档行为为分区内全部会话归档，空分区继续存在。

分叉生成新的可续聊会话，复制历史和历史证据，不重放工具、不创建任务。记录来源、赋予独立消息 ID；运行片段在快照中标记中断。旧记录可分叉成新会话、可通过现代库的独立元数据分区／归档，旧数据库始终只读。

持久化在现代 SQLite 中添加分区、归属与归档元数据，RPC 加入显式白名单。分区排序／移动在宿主事务内完成。前端保存后消费权威快照，避免过期预览或初始化覆盖新归属。归档运行会话在宿主拒绝，批量归档预检后原子提交。

验证包括原数据库升级／重启恢复、移除保留内容、归档恢复、分叉独立性与禁止重放，浏览器左键／右键一致性、菜单键盘／焦点、拖放、原有历史与输入保护，生产构建和 WebView2 隔离验收。
