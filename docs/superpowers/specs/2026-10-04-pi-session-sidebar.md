# PI-Desktop 会话侧栏移植

用户反馈 6px 滚动条难选中，要求搬入 PI-Desktop 整套侧栏交互。用户明确确认本轮范围为：会话侧栏全部交互——滚动、展开折叠、分组、预览、菜单、快捷键与拖动。

采用与既有移植一致的固定源提交 `0d47d26769ecbeca1c3ab56fa83b58a91de8190e`。保存完整 `Sidebar.tsx` 及依赖原文，迁入会话分组、悬停延迟／关闭、紧凑条目、置顶区、菜单、排序、多选与侧栏拖动。渲染调用改接现有 `ChatStore` 和 Praat RPC；保持 assistant-ui 聊天主干及 pywebview＋WebView2，不导入 Pi Agent、Electron IPC 或全局 app-store。

历史滚动通道贴边，扩大到 14px 鼠标命中宽度，静止／普通悬停时细滑块、直接悬停滑块时加粗。滑块长度由原生滚动范围计算。调节侧栏宽度的命中区域保持在边框外侧。

旧记录只读、运行会话删除保护、用户草稿／阅读位置／后台任务隔离保持。预览只加载会话详情，不切换当前会话。排序值通过宿主偏好保存，不使用 private mode 中会丢失的 localStorage。

验证包含新交互浏览器回归、原前端全量单元、相关 Python 偏好校验、TypeScript／生产构建，以及真实 WebView2 加载生产资源。
