# AIPraat Windows 安装器设计

用户已确认三步向导，并授权自行完成规格与计划审阅、直接构建。目标产物是仓库根目录的 `AIPraat-install.exe`。

## 已确认需求

1. 默认目标为 `C:\AIPraat`。目标存在时复用同一目录，不增加后缀或再次嵌套 AIPraat。允许输入完整目录或使用系统文件夹选择器。
2. 第二步选择现在配置或暂不配置。现在配置时 Python 3.10+ 的 `python.exe` 必填，校验 Tk、NumPy >= 2、Pillow >= 10。llama.cpp 的 `llama-server.exe`、模型 GGUF、视觉投影 GGUF 都可为空；非空时校验文件存在。视觉投影用于可选图像能力，MFA/wav2vec2 非基础前端必需项，不在向导中强制配置。
3. 必需项有效后，下一步按钮字体和边框从灰色变为黑色。缺失或检查中不可继续。
4. 第三步显示实际文件安装进度，后台执行保持窗口响应，成功显示“安装已完成”。失败明确报告错误，不能显示成功。
5. 构建期间低优先级测试不运行，统一在最终阶段批量运行。

## 方案与文件路径

采用系统自带 .NET Framework 的 C# WinForms。安装器本身不依赖 Python、模型或外部压缩工具，内嵌经过筛选的 ZIP 资源。包含现有 Praat.exe、AI 程序、原生插件、基础依赖清单、许可与使用说明。排除本机 ai_config.json、API key、日志、运行状态、缓存与开发测试。

安装目录包含 `Praat.exe`、`AIPraat.exe`（启动入口）、`install-settings.json`、`ai/ai_config.json`。启动入口保存正确的工作目录，并将 Python 路径、AI 项目目录、Praat 路径传递到程序；合并当前用户 `%APPDATA%\Praat\Preferences.txt` 的 `Python.executablePath` 与 `AI.projectDirectory`，保留其他设置。插件位于该用户 `%APPDATA%\Praat\plugin_praat_ai`，指向已安装目录。模型配置键为 `server.llama_server`、`server.model_path`、`server.mmproj_path`，留空时关闭自动启动，不保留开发机路径。

暂不配置时安装基础程序和 AI 程序，不要求 Python；不覆盖已有 Python 选择和已有模型配置。完成页明确提示 AI 前置可稍后配置。重新运行安装器可复用目录并配置路径。安装器不自动下载模型，也不改变用户现有 Python 环境。

## 安装与错误处理

所有目标以绝对路径处理；禁止驱动器根目录、非法路径、路径穿越和指向目录外的重解析点。后台先解压到独立临时目录，再安装有清单的文件。已有安装中只替换包拥有的文件，保留其他文件和原配置；更改文件保留备份，失败回滚本次变更。进度按实际解压/复制字节推进，配置和快捷方式完成后达到 100%。

默认无管理员权限运行；目标不可写时允许返回修改目录或选择以管理员权限重试。重试保留原始用户的首选项和快捷方式目标，安装文件夹给该用户必要的写权限；不操作 Windows 安全提示。不能在目标 Praat 运行时替换该 exe。

## 验收

检查单文件资源可独立安装、文件完整性、中文/空格路径、已有目录复用、跳过配置、Python 缺失/有效/依赖缺失、可选路径留空/有效/错误、按钮灰黑状态、系统选择器、真实进度与完成页。安装场景在独立临时目录与独立首选项目录验证，不改变本机已有 Praat 配置。最后批量跑安装器契约测试、AI 单元测试和安装后的真实 Praat/AI 启动验证，并保留日志与截图。
