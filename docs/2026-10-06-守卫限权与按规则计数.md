# 2026-10-06 守卫限权（哪些该继续当闸门、哪些退回提示词）与按规则计数

承上：`2026-10-06-对话守卫修复验收.md` 修的是"守卫与说明书不一致、拒了就丢答案"。
这一轮回答的是更上层的问题：**20 多个阻断点里，哪些真的有资格拦下整份报告。**
只改 Python（`ai/praat_ai/*.py` 与测试），没动 C++、没重编 `Praat.exe`。

## 1. 判据

一条规则配得上阻断权，要同时满足：

1. **客观**：不靠措辞、不靠风格判断（"有没有引证""够不够长"不算）；
2. **便宜**：正则/表查一下就能定，不需要额外一次模型请求；
3. **自洽**：提示词里用同样的措辞写过，且错误信息本身能让模型自己改对。

再加一条成本约束：`漏过去的危害 × 概率 ≫ 每次请求成本 × 触发概率`。
报告阶段是最大的一次请求，带音频时每次重试都要重发音频，所以"阻断"很贵。

### 保留为闸门（7 条）

| 规则 id | 拦什么 | 为什么必须拦 |
| --- | --- | --- |
| `report.object_unknown` | 引用快照/证据里不存在的对象编号 | 对象选错=结论全错（Harmonicity 事故） |
| `report.number_unmatched` | 数字在同对象/同范围/同量纲的证据里找不到 | "不许把没测过的数字当结论"是底线 |
| `report.range_whole_partial` | 整段结论引用局部分段值 | 静默换测量范围 |
| `report.prosody_untraced` | 具体录音的音调/走向结论没有走向证据 | 历史事故：拿平均值断言"平板型"并据此给练习建议 |
| `report.calc_other_target` | 推导引用了别的对象的量、冒充目标录音 | 同上（对象身份） |
| `report.calc_quantity_mismatch` | 声称"平均基频"却拿 F1 的推导 | 量名冒充 |
| `report.evidence_unknown` | 引用不存在的证据编号 | 兜底（正常已被下面的自动修清掉） |

工具侧仍是那套 A 类：对象唯一匹配/用户指定编号、整段 vs 旧选区、用户没给的名字、
自定义脚本必须是 Praat、schema/参数表校验。

### 改成自动修（7 条）

| 规则 id | 修什么 | 为什么不拦 |
| --- | --- | --- |
| `report.citation_filled` | 有数字没写引证 → 守卫自己补 `[E1]` | 引证是守卫的记账方式，不是模型要照抄的格式 |
| `report.citation_unknown` | 清掉 `[E99]` 这类不存在的编号 | 编号写错≠数字是编的 |
| `report.calc_unverified` | 算不出来的推导 → 标成 `[推导未核对]` | 这一处不成立≠整份报告在编造 |
| `report.calc_malformed` | 语法残缺的 `{{calc:…}}` → 同样标注 | 同上 |
| `report.internal_marker` | 清掉内部标记字符 | 模型不可能自己产出，清掉即可 |
| `report.coverage_repaired` | 交付项对不上 → 按原始 deliveries 补齐/裁剪 | 界面要展示的状态，修好比丢掉整份回答有用 |
| `report.prose_short` | 正文过短 → 附一句"缺少解释性正文" | 结构与长度属于提示词层要求 |

另外：**执行前被挡下的提案错误不再记 `state.failures`**（上一轮），只有真正执行过的失败
才走"两振出局"；执行失败也按 `execution.<工具>` 计数。

## 3. 怎么用这些计数

每轮的计数已经随 `state.metrics` 落库，不需要新文件：

- 新前端：`ai/runtime/modern/sessions.sqlite3` → `evidence.payload.metrics`
- 旧窗口：`ai/runtime/conversations.sqlite3` → `events(kind='turn').payload.metrics`

汇总脚本（只读、不联网、不启动 Praat）：

```powershell
python _diag/guard_stats.py            # 挡下 / 自动修 两张按规则 id 的排行榜
python _diag/guard_stats.py --turns 20 # 再看最近 20 条有守卫动作的轮次
```

指标在 `praat_ai/escape_policy.py` 的 `note_guard(state, 'block'|'repair', rule)` 一处出口，
规则 id 用稳定短串（`report.*` / `tool.*` / `execution.*`），不要塞整句中文。

## 5. 取舍与下一步

- **没有放宽"不许编造实测"**：编造的数值照样拦；放宽的只是"引证格式"和"推导写法"。
