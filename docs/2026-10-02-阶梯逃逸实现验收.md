## 已实现行为

- Pydantic Graph 负责入口、执行及独立报告节点；Pydantic AI 管理工具消息与音频协议。L0 工具执行，L1 每个问题最多一次有区别的修正，两轮无新证据停止。正常测量成功后仍进入独立 L2 解释原始目标。L3 使用实际原目标音频，L4 处理一般讨论及明确缺口。
- 未启用限制时，L2 的关键音频缺口可在当前预算内自动补一次 L3；能力、快照或预算不满足时保留阶段报告。L3 失败不抹去有效 L2 解释。
- 所有阶段共享每轮 12 次实际模型请求、20 次工具尝试。SDK/供应商重试纳入总账；临时网络、限流或兼容字段错误最多一次重试。工具阶段预留最后三次请求用于报告，取消及执行状态不明时停止后续操作。
- 上下文限制按输入及回复/误差预留判断；报告重建原目标、交付项、材料范围、有效证据及缺口。大量对象行压缩为目标摘要。关闭用户限制后忽略用户额外 token 阈值，采用 131072 token 的应用保护上限及单请求 8192 token 回复保护值；这两个值不代表任何供应商的实际窗口。未知真实容量可能在 API 返回错误后才被发现，届时尝试精简报告。
- 报告分别标记完成、部分完成、缺证据；结构校验核对目标覆盖，不宣称结论准确。工具结果、模型音频分析、一般知识与推断分别注明来源。最近四条可见对话限长保留，用于理解指代；新的独立报告不携带原工具消息链。
- 点击继续会提交一次可见 prompt，复用原目标、原范围、成功证据、前轮报告覆盖和有来源的模型音频观察，新轮次预算只在用户点击时建立。按钮传递显式模式，一般讨论无证据时也直接进入 L4。重复点击不启动第二个 worker，旧报告绑定其自己的材料。报告请求按容量摘录，完整记录保留；容量预检按实际模式计入历史对话。配置入口本身不开始分析。
- 音频复选框支持精确模型预设、未知默认关闭、手动声明、明确不支持错误纠正和可选随机合成音频验证。配置纠正采用端点/模型/适配器/账号/能力声明身份比较；同一锁内读取、合并、写入，旧结果不会覆盖新的配置或手动修改。格式、认证、限流和临时错误不被误判为模型不支持音频。
- 材料在任务开始时绑定显式对象编号/名称和时间范围；单个 PCM WAV 最多 120 秒、20 MiB，Qwen 流式 URI 请求另要求 Base64 小于 10 MiB。多对象专业测量可执行，首版直接音频输入要求明确一个主目标。原快照取得失败后不以后来移动的选区替代。
- 临时材料仅保留在当前窗口，保存来源、范围和 SHA-256 指纹，关闭后清理。下次打开聊天窗口会核验任务标记和创建进程，清理确认遗留的目录，保留活跃/身份不明任务和用户源文件。
- SQLite 记录保存可见对话、原始目标、工具提议（含原始非法参数）、执行脚本/状态、有效证据、阶段切换、模型/路径、音频请求尝试/响应确认/报告完成三种事实以及带来源的定性观察。记录不嵌入音频字节或明文凭据。重开仅查看，不恢复后台任务。
- Praat 仅在实际操作/导出时检查；云端窗口在 Praat 退出后仍可解释已有证据、使用已取得的片段或一般讨论。本地模式继续沿用跟随退出行为。

## 交付文件与运行边界

- `AIPraat-install.exe`、`AIPraat-paths.exe` 已重新构建；当前 `Praat.exe` 未修改。安装包 56,106,496 字节，最终 SHA-256 见 `installer/verification/staircase-artifacts.json`。载荷包含当前 Python 源码和使用说明，SDK 依赖由配置命令安装，不嵌入安装包。
- 源码回退点与构建前的旧两个 EXE 在 `backups/staircase-before-build-20261002/`。主要修改文件已备份；该目录不是整个工作区的完整快照。
- 固定直接依赖：`pydantic-ai-slim[openai]==2.52.0`、`pydantic-graph==2.52.0`、`jsonschema==4.26.0`。Python 3.14 仍使用 Praat 专业工具获取精确数值；条件依赖 praat-parselmouth 仅安装到 Python <3.13，未改变原清单策略。
- 未向真实供应商发出请求，未用用户录音评估发音诊断。兼容网关/模型别名仍可能有协议差异，模型预设与合成音频通过均不能证明语言学准确度；真实供应商与听感准确度验收保留为后续验证。
- 只支持当前一个 API，跨进程恢复、第二模型自动切换、长期音频存档不在首版范围。源材料的任务快照固定保留；执行新 Praat 操作时检查原进程及对象 ID/类/名称。Praat 当前对象上下文没有完整波形编辑版本号，因此身份一致不自动证明其内容未编辑，须以冻结片段和已有来源记录评估。
